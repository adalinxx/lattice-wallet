# Security

Selfhold holds signing keys. Never attach a real recovery phrase, private key, password, cookie, or backup to a report.

Report vulnerabilities privately at https://github.com/adalinxx/selfhold-wallet/security/advisories/new. Private vulnerability reporting is enabled. If that channel becomes unavailable, open an issue requesting a private reporting channel without describing the vulnerability or sharing an exploit.

Reports should identify the affected commit, a reproduction using disposable accounts and isolated nodes, the impact, and relevant logs with credentials removed. Maintainers should acknowledge privately, reproduce, preserve recovery data, and coordinate a fix and disclosure before publishing exploit details.

No independent security audit has been carried out, and none is claimed. Each release records the reviewed commit and package checksum; automated checks are not an independent audit.
